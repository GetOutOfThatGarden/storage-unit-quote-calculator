# Agent Instructions

This is a static, vanilla web project (HTML5, CSS3, Vanilla JavaScript).

## Development Workflow
- No build process or package manager (npm/yarn) is required.
- **Testing:** Open `index.html` directly in a web browser.
- **Styling:** CSS is kept in `style.css` (or embedded if simple).
- **Logic:** JavaScript is kept in `script.js` (or embedded if simple).

## Deployment
- **Target:** GitHub Pages.
- Ensure all assets have relative paths to work correctly when deployed.
